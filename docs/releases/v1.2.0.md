# HourFlow 1.2.0

## Highlights

- Added a summary format setting. Share and Download use the PDF or JPEG choice from Settings.
- Added a Download action that saves the monthly summary into the device Downloads folder.
- JSON backup export now asks where to save the file and confirms when the backup is stored.

## Editing

- Closing a shift asks before discarding unsaved changes, including a new shift.
- Closing a weekly or monthly template asks before discarding unsaved changes.
- Back, the scrim, dragging the sheet, and Cancel all use the same confirmation.

## Languages

- Updated Spanish, English, and Catalan strings for the summary format, downloads, backups, and unsaved-change prompts.
