# Changelog

## 1.0.0

Initial public release.

- Work-hour tracking by independent job.
- Monthly and yearly work summaries.
- Multiple shifts per day.
- Night-shift support for shifts that cross midnight.
- Monthly hourly rates with historical behavior.
- Extra money entries, including negative amounts.
- Weekly and monthly work templates.
- PDF and JPEG monthly summary exports.
- JSON backup and restore.
- System, light, and dark theme modes.
- Spanish, English, and Catalan UI strings.
- Gradle version bump tasks.
- GitHub Actions tests, APK artifacts, and automatic releases.
