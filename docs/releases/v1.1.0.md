# HourFlow 1.1.0

## Highlights

- Added weekly and monthly work templates.
- Added optional template descriptions and automatic schedule summaries.
- Added monthly template base selection and per-week customizations.
- Added JSON backup schema version 4 with weekly and monthly templates.
- Preserved compatibility with older JSON backup versions.

## Monthly summary exports

- Redesigned the summary screen with clearer metrics and export previews.
- Improved detailed PDF exports with columns, notes, overnight shifts, custom rates, extra money, logos, and pagination.
- Improved single-image JPEG exports with the same visual language and complete fit-to-page rendering.
- Added consistent export filenames such as `2026-08_Restaurante_Joan.pdf` and `2026-08_Restaurante_Joan.jpg`.

## Updates and backups

- Added a manual GitHub Releases link in Settings.
- Added clearer backup guidance before manually installing an APK.
- Backup filenames now use a sortable format such as `2026-08-02_HourFlow_backup_1430.json`.

## Languages

- Updated Spanish, English, and Catalan strings for templates, exports, backups, and updates.
